# 首批内容支柱与关键词集群

本规划用于组织用户问题，不代表或承诺搜索排名。正式选题前应结合 Search Console、合规要求和可获得的一手证据复核搜索意图。

## VPN 选择与评测

- 支柱页：如何选择 VPN、VPN 评测方法、VPN 价格如何比较
- 支持内容：Windows / macOS / Android / iOS 使用场景，退款政策核验，协议支持说明
- 对比意图：服务 A vs 服务 B、长期套餐与月付差异、隐私优先与易用优先

## 代理基础

- 支柱页：代理服务器是什么、HTTP 代理与 SOCKS5 区别
- 支持内容：系统代理与应用代理、DNS 解析路径、规则模式、代理认证
- 排障内容：代理连接失败、DNS 异常、应用未经过代理、证书错误

## 网络隐私

- 支柱页：个人网络隐私基础、如何建立威胁模型
- 支持内容：公共 Wi-Fi、浏览器指纹、Cookie、DNS 隐私、IP 地址的实际含义
- 决策内容：VPN、代理和加密 DNS 的边界比较

## 故障排查

- 支柱页：VPN 与代理故障排查流程
- 支持内容：连接超时、速度波动、休眠后断连、网络切换、IPv6 与 DNS 问题
- 原则：不提供绕过组织安全策略、未授权访问控制或违法用途的操作指导

## 首批发布顺序

1. 代理服务器是什么（已完成并引用 RFC）。
2. VPN 评测方法与价格表达规范。
3. HTTP 代理与 SOCKS5 的适用差异。
4. DNS 请求可能泄露哪些信息。
5. VPN 连接失败的合规排查清单。
6. 完成事实核验后的首个真实服务评测与对应对比页。
